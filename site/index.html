El merge tiene condiciones.

Con validación solicitada, pendientes y FAIL bloquean el merge. El override --force es explícito.

Disponible hoy

QA FAIL: merge bloqueado.QA PASS: merge permitido.

  1. Change implementado
  2. Validación solicitada
  3. Comprobación de veredictos
  4. Resultado del gate

Sin validación solicitada no se exige este gate. El merge va a la rama actual.

fab merge 951e7eb3 
change 951e7eb3 completado
