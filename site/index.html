Dos experiencias bajo el mismo CLI fab: una fábrica para coordinar objetivos y revisiones, y un agente para operar directamente sobre el código.

fab tui <slug>

Fábrica de software

Organiza señales, propuestas de cambio y revisiones humanas. Asigna actividades al pool de workers y custodia la integración con una puerta de merge.
