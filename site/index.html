  1. $ fab jira import FAB-142 --ws demo

    HU importada: signal 04dfa1a0

  2. $ fab triage 04dfa1a0

    signal 04dfa1a0 -> change 951e7eb3 (pending)

  3. $ fab run demo --once

    [w1-440608] investigation done in 0s
[w1-440608] implementation done in 0s

  4. $ fab validate 951e7eb3 --only qa

    Encolados 1 validadores para change 951e7eb3: qa

  5. $ fab run demo --once

    [w1-440707] change_review done in 0s

  6. $ fab validate status 951e7eb3

    ### Validación de fab change `951e7eb3` [FALLIDO]

| Validador | Veredicto | Resumen |
| --- | --- | --- |
| `qa` | **FAIL** | Fallo controlado del fixture QA. |

  7. $ fab merge 951e7eb3

    error (invalid_transition): validadores en fail: qa; usa --force para fusionar igualmente

  8. $ fab validate 951e7eb3 --only qa

    Encolados 1 validadores para change 951e7eb3: qa

  9. $ fab run demo --once

    [w1-440811] change_review done in 0s

  10. $ fab validate status 951e7eb3

    ### Validación de fab change `951e7eb3` [APROBADO]

| Validador | Veredicto | Resumen |
| --- | --- | --- |
| `qa` | **PASS** | Fixture QA aprobado. |

  11. $ fab merge 951e7eb3

    change 951e7eb3 completado
